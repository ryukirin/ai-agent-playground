## 毕业之路 ── 再向前

完成阶段 1~10 后,可向以下方向前进。

- **RAG(Retrieval-Augmented Generation)**:external memory(阶段 5)的代表。用向量检索处理大量知识。常与 MCP 的 Resources(阶段 9)结合。`rag-study/` 是手边的教材。
- **高级多智能体拓扑**:tournament(锦标赛)·self-repair loop(自我修复)·staged escalation(分级升级)等(阶段 10 的发展)。
- **评估的进阶**:LLM-as-a-judge、轨迹评估、作为回归测试的 eval 套件(阶段 7 的发展)。
- **本项目的实践**:把 `CLAUDE.md` / `共通規約/` / Skill 群 / Workflow 工具当作「Harness 设计实例」来研读,自己也试着写规约或 Skill。各阶段的「项目联动」练习就是入口。

## 重要关键词速查表

| 术语 | 含义 |
|---|---|
| **Harness** | 模型本体以外的一切(代码·配置·执行逻辑) |
| **Agent Loop / ReAct** | Thought → Action → Observation 反复的核心循环 |
| **ACI** | Agent-Computer Interface。面向智能体的工具/环境设计 |
| **Context Engineering** | 对交给模型的整个信息环境的设计 |
| **Context Rot** | 上下文越长性能越下降的现象 |
| **Compaction** | 对话历史的总结·压缩 |
| **JIT Retrieval** | 需要时动态取用信息的方式 |
| **Sub-Agent** | 委派专门任务、只返回总结的智能体 |
| **MCP** | Model Context Protocol。工具/数据连接的标准 |
| **A2A** | Agent2Agent。智能体间联动的标准 |
| **Supervisor** | 主管统领工人的多智能体默认形态 |
| **Guardrails** | 用于安全的约束·审批·检测层 |
| **Augmented LLM** | 用 retrieval + tools + memory 增强的 LLM(全系统的基础零件) |
