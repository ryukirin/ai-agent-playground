## 8-1. 讲解

### 为何要「先手写,再框架」

阶段 2~7 中,你**亲手写了** ReAct 循环·工具执行·compaction·护栏。这看似绕远,实则最短路。框架是「替你自动做好这些的盒子」,但不懂内部、出错时就不知发生了什么而卡死。Anthropic 也明言「先从直接 API 调用开始,框架要在理解机制之后」。

也就是说,框架的价值在于,**把你手写的东西换成「配置」或「几行代码」**。看得清它换掉了什么,选型和驾驭都更容易。

### 主要框架地图(2026 年)

本指南使用 **Hugging Face 的开源模型**,因此以与之契合的框架为中心列出。

| 框架 | 提供方 | 特点 | 使用的模型 |
|---|---|---|---|
| **smolagents** | Hugging Face | 极简的智能体库。`@tool` 定义工具,用 `InferenceClientModel` / `TransformersModel` 接入 HF 开源模型。以会写代码并执行的 `CodeAgent` 为特色。与 HF Hub 深度联动 | HF 任意开源模型(Qwen 等) |
| **Transformers Agents** | Hugging Face | `transformers` 内置。可**完全本地**运行智能体 | 本地 / HF 模型 |
| **LangGraph** | LangChain | 用图(状态机)定义智能体。**检查点 + time travel**(回退到过去状态)、`interrupt()` 的 human-in-the-loop 为一等公民。用 LangSmith 做可观测性。production 成熟度高。经 `langchain-huggingface` 可用 HF 模型 | 模型无关(可用 HF) |
| **CrewAI** | CrewAI | 「拥有角色(role)的智能体团队」这一直观抽象。模型无关(HF / 本地也可) | 模型无关 |
| **OpenAI Agents SDK** | OpenAI | handoff(交接)是一等原语。智能体 A 携带结构化载荷把控制交给 B,并记录转移(可回放) | OpenAI 为主 |

> 补充:`smolagents` 是 Hugging Face 的轻量智能体库。可用 `InferenceClientModel`(托管推理)/ `TransformersModel`(本地)/ `LiteLLMModel`(各类 API)替换模型。

### 选型指南

- **想用 HF 开源模型以极简方式立刻跑起来** → smolagents。
- **想完全本地 / 离线运行** → Transformers Agents(`transformers`)。
- **想严格控制复杂状态转移·回退·人类审批** → LangGraph(用 `langchain-huggingface` 接入 HF 模型)。
- **想组建基于角色的团队** → CrewAI。
- **学习阶段** → 选哪个都行,阶段 2~7 的概念原样对应。

### 框架「替你自动化的东西」对照表

| 你手写的东西(阶段) | 在框架中的替换 |
|---|---|
| `for i in range(max_iterations)` 的 ReAct 循环(F2) | SDK 内部转,你只需给出工具与目标 |
| `TOOLS` 定义 + `run_tool`(F3) | 装饰器/注册 API。`@tool` 注册函数 |
| `compact_history`(F4) | 自动上下文管理 / 检查点 |
| `_check_safety`·审批(F5·F7) | 权限配置·hooks·`interrupt()` |
| 日志输出(F7) | LangSmith 等可观测性面板 |

## 8-2. 示例代码 ── 手写循环 vs 框架

把同一个「文件调查智能体」用手写版和框架版并排。

```python
# ── 手写版(阶段2 重述·要点)──────────────────
# 定义 TOOLS → 写 run_tool → while 循环 → 以 tool 角色 append 结果 …(数十行)

# ── smolagents(Hugging Face)版(示意)──────────────────
# pip install smolagents
from smolagents import ToolCallingAgent, tool, InferenceClientModel

@tool                                  # ← F3 的工具定义+实现就这么点
def read_file(path: str) -> str:
    """读取指定路径的文本文件并返回内容。
    Args:
        path: 文件的绝对路径
    """
    with open(path, encoding="utf-8") as f:
        return f.read()

model = InferenceClientModel(model_id="Qwen/Qwen2.5-72B-Instruct")  # HF 开源模型
agent = ToolCallingAgent(tools=[read_file], model=model)
# ← F2 的循环·F4 的上下文管理由 smolagents 内部执行
print(agent.run("读取 /work/config.json 并告诉我端口号"))
```

```python
# ── LangGraph + Hugging Face 版(示意)──────────────────────────
# pip install langgraph langchain-huggingface
from langgraph.prebuilt import create_react_agent
from langchain_huggingface import ChatHuggingFace, HuggingFaceEndpoint
from langchain_core.tools import tool

@tool
def read_file(path: str) -> str:
    """读取指定路径的文本文件并返回内容。"""
    with open(path, encoding="utf-8") as f:
        return f.read()

llm = ChatHuggingFace(llm=HuggingFaceEndpoint(repo_id="Qwen/Qwen2.5-72B-Instruct"))
agent = create_react_agent(
    llm,
    tools=[read_file],
    # 传入 checkpointer=... 即可启用状态保存·回退(自动化 F4/F7)
)
result = agent.invoke({"messages": [("user", "读取 /work/config.json 并告诉我端口号")]})
print(result["messages"][-1].content)
```

两者都不过是**在内部转你在阶段 2 手写的那条 ReAct 循环**。`create_react_agent` 这个名字本身就说明了一切。
