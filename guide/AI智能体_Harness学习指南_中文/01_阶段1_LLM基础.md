# 阶段 1:LLM 基础 ── 为何需要 Harness

> [← 00 前言](00_说明.md) ｜ [02 ReAct 循环 →](02_阶段2_ReAct循环.md)

## 1-1. 讲解

### 模型只是「预测下一个词」

大语言模型(LLM)的运作本质上极其简单。它接收「至今为止的文本」作为输入,输出「接下来最可能出现的 token(词的片段)」一个。如此反复来生成文本。

这里有 3 个重要推论。

**(1) 模型是无状态的(stateless)。**
模型并不「记得」上一次的对话。聊天看起来在连续进行,是因为 Harness 一侧**每一轮都把过去的全部往来重新塞进输入**。模型本身没有记忆。这是后续阶段需要「记忆」与「上下文管理」的根本原因。

**(2) 模型只能看见上下文窗口内的东西。**
模型一次能接收的 token 数有上限(称为上下文窗口)。塞不进这个窗口的信息,对模型来说就「不存在」。无法把 100 万行的代码库整个交给它。因此「交什么、不交什么」的取舍(=上下文工程,阶段 4)极其关键。

**(3) 模型自己什么都执行不了。**
模型能用文字说「我想读文件」,但无法真的去读文件。模型能做的只有「输出文本」。真正去读文件、跑命令的,是 Harness 的工作。

### Token 与成本

模型的输入(prompt)和输出都以「token」计数并计费。中文大致 1 字约 1~2 token,英文 1 个单词约 1~数个 token。对话越长,每轮都要重新发送全部历史,token 消耗与对话长度成正比增长。这决定了智能体的成本与延迟(响应速度)。

### 系统提示词(System Prompt)

模型的输入有层级。最顶层是**系统提示词**,即「你是○○助手」「请遵守以下规则」等规定行为的最重要指令。本项目的 `CLAUDE.md` 正是对 Harness 的系统提示词(常驻指令)的一种。

> 📌 本指南的代码示例使用 **Hugging Face 的模型**(例:`Qwen/Qwen2.5-72B-Instruct`),经由 `huggingface_hub` 的 `InferenceClient`(OpenAI 兼容的 chat completions API)调用。这里用 Hugging Face Inference Providers 托管的模型,但用 `transformers` 本地运行思路相同。

### 小结:为何需要 Harness

```
模型本体     = 聪明,但「无记忆·只见窗口内·不能执行」
       ↓ 弥补这些的就是 Harness
Harness 补充的东西:
  - 保存记忆并每轮重新塞入       → 上下文管理·记忆
  - 只交付窗口装得下的部分        → 上下文工程
  - 把模型的「想做○○」真正执行    → 工具执行
  - 把这些用循环转起来           → 智能体循环
```

## 1-2. 示例代码 ── 裸 API 调用(无工具)

先体验「没有任何工具的裸模型调用」。它不是智能体,只是一问一答。

```python
# 需要 pip install huggingface_hub。请先把访问令牌设到环境变量 HF_TOKEN。
import os
from huggingface_hub import InferenceClient

client = InferenceClient(api_key=os.environ["HF_TOKEN"])
MODEL = "Qwen/Qwen2.5-72B-Instruct"   # Hugging Face 的开源模型

response = client.chat.completions.create(
    model=MODEL,
    max_tokens=1024,
    messages=[
        # 系统提示词作为第一条消息传入(system 角色)
        {"role": "system", "content": "你是一个简洁作答的助手。"},
        {"role": "user", "content": "1 到 100 的总和是多少?"},
    ],
)

print(response.choices[0].message.content)
```

接着,体会模型「无法执行」这件事。

```python
response = client.chat.completions.create(
    model=MODEL,
    max_tokens=1024,
    messages=[
        {"role": "user", "content": "读取 C:/data/report.txt 的内容并总结。"},
    ],
)
print(response.choices[0].message.content)
# → 模型只能回答「我无法访问文件」。
#    赋予它真正读取的手段(工具)是下一阶段的内容。
```

> 💡 想本地运行时,用 `transformers` 的 `pipeline("text-generation", model=MODEL)` 也能做同样的事。本指南为简洁起见统一用 `InferenceClient`。
