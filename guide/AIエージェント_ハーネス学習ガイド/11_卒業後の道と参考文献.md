## 卒業後の道 ── さらに先へ

フェーズ 1〜10 を終えたら、次の方向へ進めます。

- **RAG(Retrieval-Augmented Generation)**:external memory(フェーズ 5)の代表。ベクトル検索で大量知識を扱う。MCP の Resources(フェーズ 9)と組み合わさることが多い。`rag-study/` が手元の教材。

- **評価の高度化**:LLM-as-a-judge、トラジェクトリ評価、回帰テストとしての eval スイート(フェーズ 7 の発展)。
- **このプロジェクトの実践**:`CLAUDE.md` / `共通規約/` / Skill 群 / Workflow ツールを「ハーネス設計の実例」として読み解き、自分でも規約や Skill を書いてみる。各フェーズの「プロジェクト連動」課題がその入口。

## 重要キーワード早見表

| 用語 | 意味 |
|---|---|
| **Harness(ハーネス)** | モデル本体以外のすべて(コード・設定・実行ロジック) |
| **Agent Loop / ReAct** | Thought → Action → Observation を繰り返す中核ループ |
| **ACI** | Agent-Computer Interface。エージェント向けのツール/環境設計 |
| **Context Engineering** | モデルに渡す情報環境全体の設計 |
| **Context Rot** | コンテキストが長くなると性能が劣化する現象 |
| **Compaction** | 会話履歴の要約・圧縮 |
| **JIT Retrieval** | 必要時に動的に情報取得する方式 |
| **Sub-Agent** | 専門タスクを委譲し要約だけ返すエージェント |
| **MCP** | Model Context Protocol。ツール/データ接続の標準 |
| **A2A** | Agent2Agent。エージェント間連携の標準 |
| **Supervisor** | 監督役が作業役を束ねるマルチエージェントの既定形 |
| **Guardrails** | 安全のための制約・承認・検出層 |
| **Augmented LLM** | retrieval + tools + memory で拡張した LLM(全システムの基礎部品) |
