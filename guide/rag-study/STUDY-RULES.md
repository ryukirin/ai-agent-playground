# 学習ルール

## 基本方針

- **「動かして理解する」が最優先。** 概念だけ読んで終わりにしない。必ずコードを書いて実行し、結果を自分の目で確認する
- **比較実験で学ぶ。** 1つの手法を単独で試すのではなく、常に「手法Aと手法Bで同じ質問に答えさせたらどう違うか」を比較する
- **完了条件を満たしてから次へ進む。** learning-plan.md の各ステップにある「完了条件」をクリアしてからチェックを入れる

## 各ステップの進め方

```
1. 概念理解  → NOTE.md に概念をまとめる
2. 最小実装  → 動くコードを書く（完璧でなくていい）
3. 実験・比較 → 結果を NOTE.md に記録する
4. 振り返り  → 気づき・疑問を NOTE.md に追記する
5. チェック  → learning-plan.md の [ ] を [x] に変更する
```

## ファイル管理

- 各ステップのフォルダに `NOTE.md`（学習記録）とコードを置く
- NOTE.md には「概念」「実験結果」「気づき」「使ったコード」を記録する
- コードにはコメントで「何をしているか」「なぜそうするか」を書く
- **補足学習が発生したら、関連するNOTE.mdにも追記する。** 会話中に出た追加の概念説明・図解・比較表などは、該当ステップのNOTE.mdに漏れなく反映する

## やらないこと

- 写経（コピペして動かすだけ）で終わりにしない
- 1つのステップに完璧を求めて止まらない。70%理解できたら次へ進む
- 後のPhaseの技術を先取りしない。順番には意味がある
