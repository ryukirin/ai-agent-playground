# 1-4. Hybrid Search（BM25 + Semantic） — 学習ノート

## 概念

2つの検索手法を組み合わせる:

| 手法 | 仕組み | 得意 | 苦手 |
|---|---|---|---|
| **BM25** | キーワードの出現頻度で検索 | 固有名詞、コード片、正確な用語 | 言い換え、意味的な関連 |
| **Semantic** | ベクトル類似度で検索 | 意味的な関連、言い換え | 固有名詞、低頻度な専門用語 |
| **Hybrid** | 両方の結果を統合 | 両方の長所を活かす | やや複雑 |

## Reciprocal Rank Fusion (RRF)

BM25とSemanticの結果を統合する手法:

```
RRFスコア = Σ 1 / (k + rank)

例: ある文書がBM25で1位、Semanticで3位の場合
  RRF = 1/(60+1) + 1/(60+3) = 0.0164 + 0.0159 = 0.0323
```

- `k` はハイパーパラメータ（通常60）。ランク差の影響を滑らかにする
- スコアのスケールが異なるBM25とコサイン類似度を公平に統合できる
- LangChainでは `EnsembleRetriever` がこれを自動で行う

## 重要な気づき

- **片方の検索だけでは必ず漏れが出る** — BM25とSemanticは補完関係
- 日本語のBM25はトークナイズが重要（MeCab等の形態素解析を使うとさらに精度向上）
- RRFはシンプルだが効果的。重み付けのチューニングが不要な点が実用的
- 本格的にはLangChainの `EnsembleRetriever(weights=[0.5, 0.5])` で重みを調整できる
